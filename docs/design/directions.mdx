# Directions

This page lists the work that is agreed but not built, and the questions that are still open. Each item is described on the page it changes, where a **Direction** marker links back here. When a Direction is added, built, or dropped, this list changes in the same edit.

## Agreed, not built

- **Text fragments with prefix and suffix,** so that words that occur more than once on a page name one place. See [text fragments](documents#text-fragments).
- **Lists of lines in file addresses,** such as `#L54-L68,L80`. See [lines](documents#lines).
- **Words in single-file addresses,** written `#/page#id~text=…` and found by the web app. See [addresses in builds](documents#addresses-in-builds).
- **Commenting on a mark or a range of a chart,** named in the address by its data values. See [color](charts#color) and [addresses](documents#addresses).
- **One browser tab checks every page,** by rendering off screen the pages that it does not show. See [origins](diagnostics#origins).

## Open questions

- **Agents and background commands:** whether every agent can keep its wait for messages running. See [open questions](agent-library#open-questions).
