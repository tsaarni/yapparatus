# Directions

This page lists the work that is agreed but not built, and the questions that are still open. Each item is written out on the page it changes, next to the rule it changes, and its **Direction** marker links back here. This list only links to them. When you add, build, or drop a Direction, update this list in the same change.

## Agreed, not built

- **Text fragments with prefix and suffix,** so that words that occur more than once name one place. See [text fragments](addresses-and-context#text-fragments).
- **Words in single file addresses,** written `#/api#chat~text=log` and found by the reader app. See [links, checks, and builds](addresses-and-context#links-checks-and-builds).
- **Lists of lines in file addresses,** such as `#L54-L68,L80`, with a list in the context item. See [lines](addresses-and-context#lines).
- **Pointing at part of a chart,** a dot, a line, or a range, named after `--` by its data values. See [where the data comes from](charts#where-the-data-comes-from) and [addresses](addresses-and-context#addresses).
- **One tab checks every page,** by rendering the pages it does not show off screen. See [where diagnostics come from](diagnostics#where-diagnostics-come-from).

## Open questions

- **Agents and background commands:** whether every agent can keep its wait for messages running. See [open questions in the chat](chat#open-questions).
