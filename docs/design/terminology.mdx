# Terminology

This page explains the words that have a specific meaning in this document.

## Architecture

<Table id="terms-architecture" caption="The pieces of the system.">

| Term | Meaning |
|---|---|
| [Web app](web-app) | Shows the pages and the chat in the browser. |
| [Server](server) | Compiles the pages, serves them to the web app, and passes chat messages between the web app and the agent. |
| [Page compiler](page-compiler) | Compiles the MDX pages into JavaScript modules for the web app. |
| [Diagram compiler](diagram-compiler) | Computes the layout of a diagram from its code. |
| [Agent library](agent-library) | The agent's client of the server's REST API. |

</Table>

## Documents

<Table id="terms-documents" caption="What a document is made of.">

| Term | Meaning |
|---|---|
| [Document](documents) | A directory with a `document.json` and the pages it lists. |
| [Project](documents#projects-and-document-directories) | The directory where `pnpm dev` runs. It holds one or more documents. |
| [Address](documents#addresses) | The path of anything that can be linked to or commented on, such as `/setup#install`. |
| [External file](documents#external-files) | A file outside the project that a document shows, such as source code. |
| [Excerpt](page-compiler#code-and-excerpts) | Some lines of an external file, shown inside a page. |
| [File view](web-app#file-view) | The screen of the web app that shows one whole external file. |
| [Build](page-compiler#builds) | A document as a static website or one HTML file, without the chat. |

</Table>

## Diagrams and charts

<Table id="terms-diagrams" caption="Terms for figures.">

| Term | Meaning |
|---|---|
| [Figure](components#figures) | A diagram or chart with a number and a caption. |
| [Diagram](components#diagram) | Shapes and arrows that the agent describes in code and the diagram compiler draws. |
| [Element](diagram-compiler#ids) | One shape, arrow, or cell in a diagram. Clicking an element adds it to a comment. |
| [Step](components#steps) | A sentence that highlights some elements of a diagram. The steps are shown in order. |
| [Picture](diagram-compiler#pictures) | A PNG of a diagram, which the agent saves to see what it drew. |
| [Chart](charts) | A figure drawn from data with Observable Plot. |

</Table>

## Chat and diagnostics

<Table id="terms-chat" caption="Terms for the chat between the user and the agent.">

| Term | Meaning |
|---|---|
| [Chat](server#chat-log) | The messages between the user and the agent, shown in a panel beside the page. |
| Reader | The user's name in the chat. Prompts use it so that the agent can tell comments from the chat from what the user types directly to the agent. |
| [Agent](agent-library) | Writes replies through the agent library. |
| [Comment](web-app#commenting-on-the-page) | What the user writes about the document in the web app. |
| [Reader message](server#chat-log) | A comment as the chat stores it. |
| [Reply](agent-library#sendreply) | A message from the agent. |
| [Reference](documents#references) | What a comment refers to: selected text, a section, a figure, an element of a diagram, or lines of a file. |
| [Prompt](agent-library#prompts) | The text that the server writes for the agent. It holds the reader messages, their references, and instructions for the next step. |
| [Agent state](server#agent-state) | Whether the agent is waiting for messages, working on a reply, or away. The chat panel shows it. |
| [Diagnostic](diagnostics) | An error or warning in a document, such as a broken link or overlapping shapes. |

</Table>
